# Метр — подбор новостроек

15 ЖК в Сочи, Москве и Санкт-Петербурге. [Открыть сайт](https://novostroy-lab-20261112.sidovidchenko.chatgpt.site).

Текущий интерфейс: поиск и фильтры сверху, три лучших варианта крупно, остальные рекомендации ниже. Просмотр и скачивание таблиц с сайта удалены. Исходные исследовательские файлы сохранены в репозитории отдельно от публичной сборки.

## Рекомендации

Каждый ЖК получает независимый прямой скор сходства с запросом и активными фильтрами. Случайный лес и дополнительное переранжирование не используются. Итоговый скор — фиксированное взвешенное среднее: город 32, класс 9, текст 4, бюджет 2, площадь 2. Пустые критерии исключаются. Город имеет первый приоритет, затем класс. Подробнее — [методика](docs/model-card.md).

Текст сопоставляется по косинусу эмбеддингов RuBERT. Полное совпадение слов названия/города/застройщика/района даёт текстовый скор 1. Площадь сравнивается отношением меньшего значения к большему. В пределах бюджета сходство равно 1, выше лимита — бюджет / полная цена.

Для ЖК выбирается опубликованная квартира с лучшим совместным сходством по площади и бюджету; на карточке показаны её фактические метры и полная цена. Пересчёта минимального метра на произвольную площадь нет. Все 15 ЖК остаются в выдаче даже при отсутствии точных совпадений. Превышение бюджета, другой город/класс или существенное отклонение площади явно указаны.

Один проект имеет тот же скор в одиночку и в полном каталоге. Только готовые скоры один раз сортируются по убыванию: 3 + 12 карточек. Ручная сортировка нижнего блока удалена. Некорректные поля по-прежнему требуют исправления.

Код: [src/recommender.mjs](src/recommender.mjs). Эмбеддинги: [src/semantic-encoder.mjs](src/semantic-encoder.mjs). Старый эксперимент со случайным лесом находится в [архиве](ml/legacy-random-forest/) и в сайт не входит.

## Запуск и проверка

Нужен Node.js 20+. Приложение не требует установки пакетов или API-ключей.

```sh
npm run build
npm run dev
```

Открыть http://127.0.0.1:4173. Остановка — Ctrl+C. Другой порт: `PORT=4174 npm run dev`.

```sh
npm run check
```

Тесты проверяют прямую арифметику скора, его независимость от соседей, монотонность косинуса, сохранение всех кандидатов, отклонения, цены и источники, отсутствие публичных таблиц и загрузчика случайного леса. [Проверки](docs/verification.md).

## Источники и ограничения

`data/complexes.json` — параметры ЖК, `data/profiles.json` — описания и ссылки, `data/apartment-lots.json` — опубликованные цены отдельных квартир. Проверка источников 13.11.2026, даты прайсов различаются и сохранены отдельно. Данные — выборка, наличие при бронировании не подтверждается. У Чёрной речки, 41 один первичный лот; крупные каталоги Москвы представлены выборкой страниц. Отсутствующие цены не выдумываются.

RuBERT и ONNX Runtime поставляются с сайтом. Первая загрузка около 42 MB, инференс локальный в браузере. При отказе encoder работает прямое сопоставление слов и числовых фильтров, с явным сообщением в интерфейсе.

Сбор цен: `scripts/collect-lots.py`, нормализация: `scripts/import-lot-snapshots.py`. XLSX создаются `scripts/plain-workbook.mjs` и `scripts/area-price-workbook.mjs` в авторской среде Artifact Tool, сохраняются в outputs/ и research/, в публичную сборку не копируются.

Форма сдачи задания не отправлялась. Пользовательские трудозатраты кандидата нужно указать самостоятельно; бизнес-трек не выполнялся.
