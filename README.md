## Запуск

Нужен Node.js 20 или новее. Веб-приложение не требует установки пакетов, сервера данных или API-ключей.

```sh
npm run build
npm run dev
```

Открыть http://127.0.0.1:4173. Остановить сервер: Ctrl+C. При необходимости другой порт: `PORT=4174 npm run dev`.

```sh
npm test
```

## Как работает подбор

Сверху поиск и фильтры, ниже до трёх крупных карточек лучших вариантов и остальные подходящие ЖК компактно. При пустых фильтрах сохраняется весь каталог: 3 + 12. Город, класс и бюджет — жёсткие ограничения для обоих блоков. Сортировка меняет только нижний блок.

`расчётная стоимость = цена от за м² × желаемая площадь`

Бюджет необязателен. Цена от может относиться к квартире другой площади: это оценка проекта по таблице, наличие конкретного лота не подтверждается. Отделка, парковка, комиссии и ипотека не включены.

Поиск понимает пожелания по смыслу. Например, Москва и «дом у реки с набережной» выводят крупно Шагал, Остров и Sydney City. Эмбеддинги RuBERT размерности 312 и 41 признак поступают в RandomForestRegressor, оценивающий каждую пару «запрос — ЖК» независимо. При указании названия учитывается буквальное совпадение. У проекта есть описание и ссылки на источники характеристик. Скор не нормализуется по выдаче и не меняется при добавлении/удалении соседних ЖК. Готовые карточки сортируются по этому скору; отдельной стадии переранжирования нет.

**Обучение синтетическое**, по согласованию с пользователем: 16 815 строк / 3 233 сценария, реальных оценок покупателей нет. Ошибка отдельного скора MAE на отложенных группах запросов — 0,0808 на шкале 0–1; это соответствие синтетической рубрике, а не доказанная полезность покупателю. [Методика и ограничения](docs/model-card.md) · [Обучение, метрики и CSV признаков](ml/).

Эмбеддинги вычисляются в браузере: первая загрузка модели, словаря и WASM занимает примерно 42 MB. Внешний API инференса не нужен. При сбое модели интерфейс сообщает о переходе к буквальному поиску. Параметры сохраняются в URL; устаревшие ответы при быстром вводе игнорируются.

## Данные и обновление

- Цены и параметры исследования: `data/complexes.json`; описания и ссылки для ML: `data/profiles.json`. `sourceUrl` подтверждает цену; `deliverySourceUrl` — срок, если источник другой. Есть дата, способ проверки и примечание.
- Источники — открытые каталоги. Даты прайсов различаются; у «Острова» использован поисковый снимок от 23.10.2026, у Olivia — индексированная выдача из-за капчи. Эти строки требуют повторной прямой проверки перед окончательной сдачей.
- В Сочи все 5 выбранных ЖК бизнес-класса; в Москве 2 бизнес/3 премиум, в Петербурге 3/2. Сравниваются минимальные цены внутри этой выборки: Москва — 422 000, Сочи — 290 000, Санкт-Петербург — 348 400 ₽/м². У «Острова» и МИРЪ класс в разных каталогах расходится.
- Для обновления нужно открыть источники, изменить JSON, переобучить модель по инструкции в model-card, затем пересобрать CSV и сайт командой `npm run build`, график — `python3 scripts/chart.py`, XLSX — `node scripts/workbook.mjs`. Для графика нужен Matplotlib; для XLSX — авторская среда `@oai/artifact-tool`. Эти инструменты не нужны пользователю подборщика. Готовые XLSX и график уже включены в репозиторий.
- Полные URL в XLSX записаны значениями: используемый генератор не вычислял HYPERLINK корректно. Веб-таблица и Markdown содержат кликабельные ссылки.

## Структура

```text
data/complexes.json      единая таблица с источниками
data/profiles.json       описания, теги и источники характеристик
ml/                     экспорт encoder, обучение, метрики, таблица признаков
src/                    HTML, CSS, JS, ONNX-модель и runtime
scripts/                сборка, локальный сервер, график, XLSX
tests/                  проверки подбора и данных
research/               CSV, Markdown-таблица, график
docs/                   выводы, методика, журнал работы с ИИ
dist/                   готовый сайт и все скачиваемые материалы
```

В браузере нет запросов к LLM: ИИ помог собрать и проверить данные и написать код, а расчёты детерминированы. Шрифт Golos Text поставляется локально с [SIL Open Font License](src/fonts/OFL.txt).

В журнале приведены пять фактических запросов пользователя, включая согласование синтетического обучения. Личные трудозатраты кандидата нельзя определить по работе агента: перед сдачей их нужно указать самостоятельно. Время AI-сессии фиксируется в журнале.
