## Запуск

Нужен Node.js 20 или новее. Веб-приложение не требует установки пакетов, сервера данных или API-ключей.

```sh
npm run build
npm run dev
```

Открыть http://127.0.0.1:4173. Остановить сервер: Ctrl+C. При необходимости другой порт: `PORT=4174 npm run dev`.

```sh
npm test
```

## Как работает подбор

`расчётная стоимость = цена от за м² × желаемая площадь`

Сверху расположены строка поиска и фильтры, снизу — карточки всех подходящих ЖК. По умолчанию показаны все 15 проектов. Поиск работает по названию, застройщику, району и городу; учитываются все введённые слова, регистр и различие е/ё не важны. Фильтры города, класса и бюджета применяются совместно и сразу при вводе. Бюджет необязателен; если он указан, для расчёта нужна площадь. Сортировка — цена за м² по возрастанию/убыванию или название. Есть сброс фильтров.

Для Москвы, 30 млн ₽, 50 м² показаны все четыре подходящих ЖК: Шагал — 21,1 млн, Символ — 22,185 млн, Sydney City — 27,665 млн, Остров — 29,39 млн ₽. Параметры сохраняются в URL. Обновление фильтров сохраняет фокус, прокрутку и элементы карточек.

Цена от может относиться к квартире другой площади. Приложение подбирает ЖК по таблице, не подтверждает существование конкретного лота. Отделка, парковка, комиссии и ипотека не включены. Это ограничение видно в интерфейсе.

## Данные и обновление

- Единственный источник данных: `data/complexes.json`. `sourceUrl` подтверждает цену; `deliverySourceUrl` — срок, если источник другой. Есть дата, способ проверки и примечание.
- Источники — открытые каталоги. Даты прайсов различаются; у «Острова» использован поисковый снимок от 23.10.2026, у Olivia — индексированная выдача из-за капчи. Эти строки требуют повторной прямой проверки перед окончательной сдачей.
- В Сочи все 5 выбранных ЖК бизнес-класса; в Москве 2 бизнес/3 премиум, в Петербурге 3/2. Сравниваются минимальные цены внутри этой выборки: Москва — 422 000, Сочи — 290 000, Санкт-Петербург — 348 400 ₽/м². У «Острова» и МИРЪ класс в разных каталогах расходится.
- Для обновления нужно открыть источники, изменить JSON, затем пересобрать CSV и сайт командой `npm run build`, график — `python3 scripts/chart.py`, XLSX — `node scripts/workbook.mjs`. Для графика нужен Matplotlib; для XLSX — авторская среда `@oai/artifact-tool`. Эти инструменты не нужны пользователю подборщика. Готовые XLSX и график уже включены в репозиторий.
- Полные URL в XLSX записаны значениями: используемый генератор не вычислял HYPERLINK корректно. Веб-таблица и Markdown содержат кликабельные ссылки.

## Структура

```text
data/complexes.json      единая таблица с источниками
src/                    HTML, CSS, браузерный JS, функция подбора
scripts/                сборка, локальный сервер, график, XLSX
tests/                  проверки подбора и данных
research/               CSV, Markdown-таблица, график
docs/                   выводы, методика, журнал работы с ИИ
dist/                   готовый сайт и все скачиваемые материалы
```

В браузере нет запросов к LLM: ИИ помог собрать и проверить данные и написать код, а расчёты детерминированы. Шрифт Golos Text поставляется локально с [SIL Open Font License](src/fonts/OFL.txt).

Материалы пяти промптов честно разделены на три фактических запроса и две реконструкции этапов. Личные трудозатраты кандидата нельзя определить по работе агента: перед сдачей их нужно указать самостоятельно. Время AI-сессии фиксируется в журнале.
