# Проверка версии с ML-рекомендациями

13.11.2026, локальный HTTP-сервер, Chromium через Playwright.

- `npm run check`: 25 тестов и сборка. Проверяются данные, бюджет, признаки Python/JavaScript, токенизация, экспорт деревьев scikit-learn, источники описаний, эмбеддинги, SHA-256 весов, три крупных карточки, отсутствие дублей, жёсткие ограничения, пустые/неверные критерии, резервный режим и разделение train/validation/test.
- Реальный ONNX Runtime Web: 312-мерные векторы на трёх проверочных фразах совпали с Python ONNX Runtime, косинус выше 0,99999. Прогноз JSON-деревьев на 25 примерах соответствует scikit-learn с погрешностью меньше 1e-8; таблица признаков — 2e-5.
- Москва / «дом у реки с набережной»: крупно Шагал, Остров, Sydney City; ниже Символ и PRIME PARK. Названия слов запроса не содержат: выполняется семантическое ранжирование.
- Москва / премиум / 30 млн / 50 м²: два крупных варианта, Остров и Sydney City, без искусственного заполнения третьего. При бюджете 1 млн — пустое состояние.
- Сброс: три крупных и двенадцать компактных карточек, всего 15 уникальных ЖК. Бюджет, город и класс применяются ко всем карточкам.
- Быстрый ввод: искусственно задержан ответ на «жизнь у моря», затем введено «Шагал». После прихода обоих ответов первым остаётся Шагал; поле и URL содержат последний запрос, фокус остаётся в строке поиска.
- Принудительно заблокированы файлы ONNX: интерфейс сообщает о резервном буквальном поиске, по «Шагал» показывает один ЖК; режим literal-fallback. После снятия блокировки и перезагрузки восстанавливается hybrid-ml.
- На ширинах 320/390/768/1024/1440 px горизонтального переполнения страницы нет. Найденное на 320 px переполнение заголовка нижнего блока исправлено переносом.
- При обычной успешной загрузке ошибок/предупреждений консоли не обнаружено. Предупреждение резервного режима при искусственной блокировке ожидается.

Сохраняются ранее проверенные артефакты исследования: 15 строк таблицы, фильтр Сочи — 5; 15 столбиков графика; минимальные цены Москва 422000 / Сочи 290000 / Санкт-Петербург 348400 ₽/м². XLSX имеет MIN и INDEX/MATCH в сводке; оба листа проверены расчётами, структурой и рендером. Нативный Microsoft Excel не запускался.

Цены — срез 12.11.2026. У Olivia и Острова использован поисковый индекс; ограничения и расхождения отражены в данных. Проверки приложения не подтверждают наличие конкретных квартир. Нативные Safari/iPhone не проверялись. Качество рекомендаций оценивалось на синтетической разметке; реальная история выбора отсутствует. Первая загрузка encoder/runtime — примерно 42 MB.
