    01

    Сбор и проверка

    С помощью ChatGPT собраны кандидаты, затем сверены цены, класс и сроки в открытых каталогах. Комфорт-класс и апарт-отели исключены. Для двух страниц использована индексированная выдача — это отмечено в строках.

    02

    Исправленная ошибка

    В черновик для «Шагал» попала устаревшая цена из поисковой выдачи — 435 000 ₽/м². Открытая страница на 12.11 показывала 422 000 ₽/м². В итоговые данные перенесено новое значение, расчёты пересчитаны.
